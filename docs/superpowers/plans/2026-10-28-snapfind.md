# SnapFind Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static, local-first web app that embeds uploaded images with a local model and ranks them for Arabic/English text queries.

**Architecture:** Vanilla JS + Vite. Main thread owns UI, IndexedDB and the queue; a Web Worker owns Transformers.js; OCR uses a Tesseract.js worker. All model/runtime assets are fetched from Hugging Face (models) or self-hosted (ORT WASM, Tesseract core + traineddata).

**Tech Stack:** Vite 8, @huggingface/transformers 4.3.2, tesseract.js 7, vitest 5 + fake-indexeddb, Playwright (preinstalled Chromium).

**Spec:** `docs/superpowers/specs/2026-10-28-snapfind-design.md`

**Execution method:** Native (executing-plans) — Mohd asked for continuous execution.

## Global Constraints

- Max file size 10 MB (10 * 1024 * 1024 bytes); accepted types image/jpeg, image/png, image/webp, image/gif.
- No backend, no external service receives images, queries, OCR text or embeddings.
- Arabic is the default locale (`dir="rtl"`), English switchable (`dir="ltr"`).
- DB name `snapfind`; never delete/clear the DB in app code except explicit user "Delete" / "Delete all" with confirm.
- No claim of offline support unless tested.

## Review Focus

1. Tab closed while an image is `processing` → on reload it must be re-queued, not lost or stuck. (Task 3 test `recovers stuck processing records`)
2. Model download fails (offline/blocked host) → visible error + Retry button; queued images stay queued. (Task 4 e2e `model failure shows retry`)
3. Search typed before model ready → clear "model still loading" message, query runs once ready. (Task 5 test)
4. Non-image or >10 MB file mixed in a multi-file upload → others still accepted, rejected ones listed with reason. (Task 2 test)
5. Same image uploaded twice → stored once (content hash) so library and results don't duplicate. (Task 2 test)
